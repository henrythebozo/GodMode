What would actually make it better

The model trails the bookmaker by about 0.01 log loss. That gap is information the market has and this data doesn't. In rough order of payoff:

  • Injuries, suspensions and line-upsbiggest gain The single largest thing the market knows and the results file doesn't. Needs a lineup feed pulled before kick-off.
  • Expected goals (xG) historylarge Shots on target are a crude proxy. football-data.co.uk now ships HxG/AxG for recent seasons; a rolling xG-for/against feature is a small change to train.py.
  • Time-decayed trainingmedium Weight recent seasons more. Football in 2006 is not football in 2026.
  • Per-league home advantage in Elomedium Home advantage is 60 points everywhere right now; the Tables tab shows it differs by league.
  • Dixon–Coles correctionsmall Independent Poisson under-predicts 0–0 and 1–1. Only affects scorelines, not the win/draw/loss call.
  • Market odds as a featurecircular Would close most of the gap instantly, but then the bot is just repeating the bookmaker. Fine for a betting tool, pointless for analysis.

Retraining is one command and the weekly GitHub Action does it automatically:

pip install -r sportsbot/requirements.txt
python sportsbot/fetch_data.py --refresh-current
python sportsbot/train.py
