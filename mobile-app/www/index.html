Sign in

OpenRouter is the only one of the four that a page with no server can sign you into: it does OAuth with no client secret to hide. Anthropic has no third-party sign-in at all — its OAuth is reserved for Anthropic's own apps, and a claude.ai login grants no API access — and Google's needs a Cloud project and a consent screen, which is more work than pasting a key. Since OpenRouter brokers Claude, Gemini and GPT, signing in there reaches all three anyway.

Or bring your own key

An OpenRouter key (300+ models) or your own OpenAI / Anthropic / Gemini key. Everything — keys, memory, reminders, notes — is stored only on this device.

Copy a key from any of these and paste it anywhere in Jarvis — it recognises which provider it belongs to and files it for you. No field-hunting.

Smart Home

A virtual home (lights, a lock, a thermostat, two scenes) works out of the box in the Systems view and by voice — no setup needed. To control real devices, connect a Home Assistant instance — it bridges Hue, Nest, SmartThings-paired devices, Sonos and most other smart-home brands through one local API.

Your Home Assistant instance must allow requests from this page's origin (set http.cors_allowed_origins in configuration.yaml, or use a Nabu Casa URL).

Media Generation (Higgsfield)

Lets Jarvis generate images — and video, once you set a model below — with Higgsfield AI. Get an API key id and secret from cloud.higgsfield.ai.

Only the image endpoint is in Higgsfield's public docs; find the video one for the model you want in your Higgsfield Cloud dashboard and paste its path here.

Logo

Background Documents

Import plain-text work — notes, briefs, price lists, transcripts, exported docs (.txt, .md, .csv, .json). Jarvis reads these when a question calls for them.

PDFs and Word files can't be read here — this app has no document parser and adding one would mean pulling in an external library. Copy the text out and paste it into Background above, or save it as .txt first.

Calendar — read-only

Shows upcoming events from a calendar you export as an .ics file — Google Calendar, iCloud, Outlook and most others can export one from their settings. Most calendar hosts don't let a webpage fetch their feed directly (a browser rule called CORS — checked against Google, iCloud and Outlook, none allow it), so uploading the file is the reliable path. Syncing a URL below works only for feeds that happen to allow cross-origin requests, which self-hosted calendars often do.

Vault folder

Point this at the folder the jarvis CLI uses and both halves keep the same notes — the same markdown files Obsidian opens. Syncing is manual: nothing is read or written until you press it.

Backup

Export everything Jarvis knows on this device — memory, reminders, notes, chat history, recordings and devices — to a JSON file, and re-import it later or in another browser.

Reset

Erases everything Jarvis has stored on this device — memory, reminders, notes, history, recordings, devices, keys and preferences — and reloads the page. This cannot be undone.
